## How should you compare quality fairly?

Use the same source, duration and dimensions. Save each original output and record the application/model version, date, selected quality, encoding settings, elapsed time and total cost. Inspect hair, fur, hands, occlusion and fast motion against several backgrounds, then listen to the entire audio track. A sharp still frame can hide temporal flicker.
